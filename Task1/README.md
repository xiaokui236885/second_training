# 任务1：opencv图片处理
## 1.项目简介
使用郁金香图片练习颜色空间转换、滤波、颜色分割、形态学操作和轮廓筛选
## 2.环境信息
操作系统：Ubuntu 22.04 LTS
编译器：GCC（g++）11.4.0
构建工具：CMake 3.22.1
opencv版本：4.5.4
## 3.目录结构
```text
Task1/
├──CMakeLists.txt
├──flower.cpp
├──flower.jpg
├──build/
├──README.md
```
## 4.构建步骤
```bash
cd ~/Code/Task1
cmake -S.-B build
cmake --build build
./build/flower
```
## 5.运行结果
（1）读图与颜色转换：灰度图与HSV通道分离
（2）滤波对比：均值、高斯、中值滤波
    滤波类型 核尺寸 其他参数
    均值滤波 5x5    无
    高斯滤波 5x5   sigma = 1.5
    中值滤波 5      无
（3）红色提取：HSV双区间红色掩膜
    通道    区间1   区间2
    H       0～10   170～180
    S       80～255 80～255
    V       80～255 80～255
（4）形态学与轮廓：对掩膜分别展示腐蚀、膨胀、开运算、闭运算的效果；
                筛选出面积大于500像素点的轮廓，其中：
                轮廓 2 面积: 536.5
                轮廓 6 面积: 8579.5
                轮廓 7 面积: 549.5
                轮廓 9 面积: 2089.5
                轮廓 17 面积: 109896
                轮廓 18 面积: 539591
（5）绘制与变换：在原图副本上绘制圆、矩形和文字“flower；绕图像中心旋转35°；单独裁剪原图左上角 1/4，即原宽、原高各取一半。
